| cart-service → catalog-service | Internal batch pricing call trusts network placement, validates payload shapes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-04-01 | Spoofing | Identity via request body | high | mitigate | Contract forbids userId in bodies; identity exclusively from verified sub claim — acceptance-grepped negative on requestBody properties |
| T-04-02 | Tampering | Client-supplied prices/totals | high | mitigate | Bodies carry productId+quantity only; unitPriceCents/lineTotalCents/grandTotalCents appear solely in RESPONSE schemas recomputed server-side |
| T-04-03 | Elevation of Privilege | Catalog write endpoints | high | mitigate | create/update/delete/batch-write class declared bearerAuth explicitly; only GETs public per GTWY-03 matrix |
| T-04-04 | Denial of Service | Unbounded quantities/lists | medium | mitigate | quantity minimum 1; limit parameter maximum 100 on listing; batch minItems 1 (upper bound noted as Phase 4 implementation concern) |
| T-04-05 | Information Disclosure | Internal edge exposure | medium | mitigate | /cart/{userId} and /health described network-internal and not-gateway-routed; Phase 7 port revocation enforces mechanically |
