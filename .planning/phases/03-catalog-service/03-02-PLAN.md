<section role="flagged-assumptions">
## Flagged Assumptions (Edge Probe — CAT-03, CAT-04 unresolved/unclassified)

Surfaced per the specless fallback (never silently dropped):

- **CAT-03 (unclassified):** Category filter is exact string equality (`{"category": x}`). An unknown category returns `items=[]` and `total=0`. No partial/substring matching.
- **CAT-04 boundary:** `limit < 1` or `> 100`, and `offset < 0`, are rejected with 400 VALIDATION_FAILED via Pydantic Query constraints. At `limit=100` at most 100 items return; requesting more is capped, not errored. `offset` beyond collection size returns empty items with unchanged `total`.
- **CAT-04 adjacency:** Equal primary-sort keys (ties) have an unspecified contract order; ASSUMPTION: a deterministic secondary sort by `_id` ascending makes listings repeatable.
- **CAT-04 empty:** empty `q` (`""`) or absent `q` omits the `$text` clause (all products match ignoring q); empty `category` omits the category filter; a single-element collection returns that element.
- **CAT-04 encoding:** Text search length/tokenization follows MongoDB `$text` default term tokenization; no custom normalization is applied.
- **CAT-04 ordering:** Primary sort is numeric-exact on `priceCents` (integer) or lexicographic on `name`; ties broken by `_id` (see adjacency).
- **CAT-04 precision:** `priceCents` is an integer; numeric sort is exact with no float rounding; tie-break is stable.
