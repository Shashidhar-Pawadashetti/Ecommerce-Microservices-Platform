## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→catalog API | untrusted browser/storefront input (query params, path ids) crosses here |
| catalog→MongoDB | trusted internal datastore access |
| catalog→JWT_SECRET | secret material read from env at startup |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Elevation (broken access control) | POST/PUT/DELETE /catalog/products | high | mitigate | `require_auth` dependency on every mutating route (defined here, enforced Plan 04); default-deny — only routes declaring `security: []` are public |
| T-03-02 | Tampering/Spoofing (JWT alg confusion) | security.py | high | mitigate | `jwt.decode(..., algorithms=["HS256"])` only; base64-decoded secret; validate `iss=ecommerce-auth`, `aud=ecommerce-api` (Plan 04) |
| T-03-03 | Tampering (NoSQL injection) | routes.py listProducts filter | medium | mitigate | Exact-match `{"category": x}`; `$text` index for search (not interpolated `$regex`); never pass raw request JSON into `find()` — Plan 02 |
| T-03-04 | Info Disclosure | main.py exception handlers | medium | mitigate | Generic `{"code","message"}` envelope; no stack/driver internals; `JWT_SECRET` never logged |
| T-03-05 | Tampering (mass assignment) | models.py ProductWrite | low | mitigate | ProductWrite excludes `id`/`createdAt`; server generates them; `extra="ignore"` |
| T-03-SC | Tampering | pip/uv installs | high | accept | Package Legitimacy Audit in 03-RESEARCH.md cleared all packages (no SLOP/SUS); no blocking human checkpoint required |
</threat_model>
