## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering/Elevation | JWT algorithm confusion (alg swap, unsigned variants) | critical | mitigate | Encoder pins JWSHeader HS256 explicitly (Task 2); decoder constructed via withSecretKey so only MAC-family verification exists (Task 2); wrong-algorithm rejection test in Task 3 |
| T-02-02 | Information Disclosure | User enumeration via divergent errors/timing | high | mitigate | Byte-identical 401 envelopes + dummy bcrypt compare for unknown accounts (Task 2 tests assert body equality) |
